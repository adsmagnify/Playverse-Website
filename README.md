# PlayVerse.gg

Crazy esports events website — LANs, arena majors, creator stages.

## Run

```bash
npm install
npm run dev
```

## Vibes

- Cyan / magenta / lime HUD aesthetic
- Glitch titles, RGB cursor trail, scanlines
- Dual marquees, 3D event cards, floating orbs
- Lenis smooth scroll + neon progress bar

## Routes

`/` · `/events` · `/events/[slug]` · `/about` · `/contact`
